## App info
Simple memory training game.  Click on all 12 images but you can only click on each once or else you lose.  After every click the images get scrambled so you must remember which images you have clicked on and which images still need to be clicked on.

## Development

Requires Node.js 20.19+ (or 22.12+).

```sh
yarn install
yarn start      # dev server at http://localhost:5173
yarn test       # run the tests (Vitest)
yarn build      # production build in ./build
yarn deploy     # build and publish ./build to GitHub Pages
```

Built with [React](https://react.dev) and [Vite](https://vite.dev).
